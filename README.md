# AI Engineering Projects

A portfolio of production-style AI engineering projects — RAG pipelines, LLM integrations, and intelligent agents. Each project is self-contained with its own README, runnable code, and a clear problem statement.

---

## Projects

| Project | Description | Stack |
|---|---|---|
| [document-qa](./document-qa/) | RAG system that answers questions about any document with source traceability | Python, FastAPI, Groq (LLaMA 3.1) |
| [llm-eval-harness](./llm-eval-harness/) | Runs any question through 4 LLMs in parallel and scores each answer on faithfulness, relevance, cost, and latency | Python, FastAPI, OpenAI, Groq, LLM-as-judge |

---

## Goals

This repo tracks my work building practical AI systems — not toy demos, but things that solve real problems and could slot into a production codebase. Each project targets a specific engineering pattern (RAG, tool use, agents, eval) and is built to be readable and extensible.

---

## Running any project

Each project has its own `README.md` with setup and run instructions. All projects use Python 3.11+ and a local `.env` for API keys.
